# PID регулятор

Проект для научной конференции: **Инженеры будущего (2025)**

---

## О проекте

Проект представляет собой полностью готовый стенд для стабилизации инертных объектов на подвижной плоскости.

### Компоненты стенда

| Компонент | Назначение |
|-----------|------------|
| Камера | Отслеживание положения шарика |
| ПК / Raspberry Pi | Обработка видео, вычисление координат |
| Arduino | PID-регулятор, управление сервоприводом |
| Сервопривод | Поворот платформы |
| Дополнительное питание (5В / 2А+) | Питание сервопривода |
| Макетная плата | Разводка питания и сигналов |
| Подвижная платформа | Физическая основа стенда |

### Принцип работы

1. Камера захватывает видео и передает на ПК
2. Python-скрипт обрабатывает кадры, находит координаты шарика
3. Координаты отправляются в Arduino через Serial
4. Arduino вычисляет PID-коррекцию и подает PWM-сигнал на серву
5. Серва поворачивает платформу, возвращая шарик в центр

## Принципиальная схема работы

```mermaid
flowchart LR
    subgraph PC["Python на ПК"]
        direction TB
        CameraScript["PID_camera_script.py<br/>─────────────<br/>захват кадров<br/>поиск координат"]
    end
    
    subgraph ARD["Arduino"]
        direction TB
        PID["pid_regulator.ino<br/>─────────────<br/>чтение Serial<br/>PID вычисление<br/>PWM сигнал"]
    end
    
    subgraph HW["Железо"]
        direction TB
        Servo["Сервопривод"]
        Platform["Платформа"]
        Servo --> Platform
    end
    
    PC ==>|"координаты x,y<br/>(через Serial)"| ARD
    ARD ==>|"PWM сигнал"| HW
    Platform -.->|"обратная связь<br/>(изменение положения)"| PC
```

## Схема подключения

```mermaid
flowchart LR
    Camera[Камера] --> PC[ПК / Raspberry Pi]
    PC -->|USB| Arduino[Arduino]
    
    subgraph Power[Питание]
        ExtPower[Доп. питание<br/>5В / 2A+]
    end
    
    Arduino -->|PWM сигнал| Servo[Сервопривод]
    ExtPower -->|VCC +5В| Servo
    ExtPower -->|GND| Servo
    
    Ball[Шарик] -.->|отслеживание| Camera
    Platform[Подвижная платформа] --- Servo
```
